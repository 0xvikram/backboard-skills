# Backboard

Backboard is a free, unofficial board of developer tools for hackers at ETHGlobal Mumbai, ranked by upvotes from hackers: https://backboard.0xvikram.me

## When the user says what they're building

1. Read https://backboard.0xvikram.me/llms.txt. It lists every checked tool on the board by category, with the prize tracks it fits, the chains it works on, its docs for AI assistants, its MCP server and its upvotes.
2. Suggest 2 to 4 tools that fit what they're building and the prize track they want. Say why each fits, and mention when two tools overlap.
3. Tell them each tool's install command for its own skill when llms.txt lists one (for example `npx skills add 0xvikram/backboard-skills --skill privy`).

## Before you write code with any tool

- Read that tool's docs for AI (its llms.txt) or its docs, and use its MCP server if it has one. Follow the current API instead of what you remember.
- Check the latest version of its package before you install it.

## Hackathon facts

- Hacking starts Thursday 5 Nov 2026, 9:00 pm IST, per ETHGlobal's schedule.
- Prize rules and details are only on ETHGlobal's official page: https://ethglobal.com/events/mumbai/prizes. Never guess a prize's rules; link to that page.
- Backboard is independent and is not affiliated with ETHGlobal or its sponsors. "Likely fits" on a tool is Backboard's suggestion; "Helps with" was chosen by the tool's own team.
