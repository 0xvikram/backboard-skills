# Changelog

All notable changes to this repository. Dates are in UTC.

## Unreleased

### Added
- Tested, hand-written skills for Alchemy, Pimlico, Privy, Dynamic and thirdweb: quickstart, 7–8 recipes, 11–13 common errors, sponsor-chain support and MCP setup each; every code example type-checked, with builds and offline tests where possible.

## 0.2.0 — 2026-10-19

### Added
- README with a quickstart, how skills work, an FAQ and a catalog of every skill, rebuilt automatically.
- Checks on every pull request: front matter, names, file links, and blocked patterns (piped installers, keys, secrets).
- A weekly link check that opens an issue when a link breaks.
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, a rewritten `CONTRIBUTING.md`, issue templates, a pull request template and `CODEOWNERS`.
- `license`, `category`, `website` and `source` metadata on every generated skill.
- `sponsor-chains`: chain IDs, RPCs, explorers, faucets, viem exports and deploy gotchas for World Chain, Unichain, Hedera, Arc, 0G and Whitechain, each checked against the live RPC.
- 12 prize-track guide skills (`track-<sponsor>`): the board's tools that fit each track and past winners for ideas, linking to ETHGlobal for the rules.
- Exact MCP server setup for Claude Code and Cursor in the 11 tool skills whose tool has an official MCP server.

## 0.1.0 — 2026-10-19

### Added
- Generated skills for the 42 tools listed on [Backboard](https://backboard.0xvikram.me).
- The `backboard` guide skill, which suggests tools from the live board.
